# শুনুন — বাংলা ও ইংরেজি AI Text-to-Speech ওয়েবসাইট

এটি একটি প্রাথমিক, চালু করার উপযোগী MVP। ব্যবহারকারী লেখা পেস্ট করে ভাষা ও কণ্ঠ বেছে নিলে সার্ভার xAI Text-to-Speech API-তে অনুরোধ পাঠায় এবং MP3 অডিও ফেরত দেয়।

## চালু করার জন্য যা লাগবে

- Node.js 20 বা নতুন
- xAI API key (API ব্যবহারে খরচ হতে পারে)
- ওয়েবসাইট হোস্ট করার একটি Node.js-সমর্থিত সার্ভিস

## নিজের কম্পিউটারে চালানো

1. ZIP ফাইলটি Extract করুন।
2. টার্মিনালে প্রকল্পের ফোল্ডারে যান।
3. `npm install` চালান।
4. `.env.example` ফাইলটির নাম বদলে `.env` করুন।
5. `.env` ফাইলে `XAI_API_KEY=...`-এর জায়গায় নিজের API key বসান।
6. `npm start` চালান।
7. ব্রাউজারে `http://localhost:3000` খুলুন।

## অনলাইনে প্রকাশ

Render, Railway বা অন্য Node.js hosting-এ এই ফোল্ডারটি deploy করুন।
- Build command: `npm install`
- Start command: `npm start`
- Environment variable: `XAI_API_KEY` = আপনার API key
- চাইলে `TTS_REQUESTS_PER_HOUR` সেট করুন।

API key কখনো GitHub-এ, HTML/JavaScript ফাইলে, বা ব্যবহারকারীর ব্রাউজারে প্রকাশ করবেন না।

## গুরুত্বপূর্ণ সীমাবদ্ধতা ও পরবর্তী কাজ

- এই সংস্করণে প্রতি অনুরোধে সর্বোচ্চ ১২,০০০ অক্ষর; বড় লেখা কয়েক ভাগে দিতে হবে।
- API খরচ নিয়ন্ত্রণে প্রতি IP-তে ঘণ্টায় ২০টি অনুরোধের প্রাথমিক সীমা আছে। পাবলিক লঞ্চের আগে CAPTCHA, আরও শক্তিশালী abuse protection, দৈনিক সামগ্রিক খরচ-সীমা এবং monitoring যোগ করুন।
- অডিও ফাইল সার্ভারে স্থায়ীভাবে রাখা হয় না; ব্রাউজারে তৈরি URL দিয়ে শোনা/ডাউনলোড করা যায়।
- কণ্ঠগুলোর নাম API-র voice ID। কোন কণ্ঠের লিঙ্গ/বাংলা উচ্চারণ সবচেয়ে ভালো, তা বাস্তব নমুনা শুনে নির্বাচন করুন।
- ফেসবুকের private বা login-protected পোস্ট স্বয়ংক্রিয়ভাবে আনা হয় না; লেখা কপি করে পেস্ট করতে হবে।
- ব্যবহারকারীকে জানানো হয় যে কণ্ঠটি AI-generated।

## প্রযুক্তিগত নোট

TTS API: `POST https://api.x.ai/v1/tts`
ভাষা: বাংলা `bn`, ইংরেজি `en`
বর্তমান কোডে ব্যবহৃত voice IDs: `ara`, `eve`, `rex`, `sal`, `leo`

প্রকাশের আগে xAI-এর বর্তমান API documentation, pricing, voice availability এবং terms যাচাই করুন।
